# Codex 插件使用说明

Codex 作为独立的 `pi-web.codex` 插件运行，入口位于 Workspace 工具栏的 Terminal 之后。命令面板也可搜索 **Go to Codex**。插件通过宿主工作区接口通信，沿用机器路由、鉴权和布局；Codex 会话与 Pi 聊天独立。

## 安装和启动

1. 在工作区所在机器安装 Codex CLI，并运行 `codex login` 完成登录。确保启动 `pi-web-sessiond` 的环境可以找到 `codex`，可先执行 `codex --version`。
2. 在本补丁仓库执行 `sh scripts/sync.sh`，然后执行 `sh scripts/install.sh`。
3. 手动重启 sessiond 和 Web 服务。例如使用本仓库管理脚本的实例执行：

   ```bash
   bash scripts/pi-web-run-jmfederico.sh stop --port 25224
   bash scripts/pi-web-run-jmfederico.sh start --port 25224
   ```

   端口和环境变量应与原实例一致。重启会中断正在运行的任务，应先等待任务结束。
4. 选择工作区，打开 **Codex** 后进入会话首页。点击列表中的会话查看历史；也可直接在底部输入并发送，自动新建会话。会话内点击左上角标题前的 **←** 返回首页。

本次验证版本为 **codex-cli 0.162.1**，使用 `codex app-server --listen stdio://`。未对更早版本承诺兼容；初始化或协议操作失败时，请先核对版本和 sessiond 的 PATH。协议依据为 [Codex App Server 官方文档](https://developers.openai.com/codex/app-server)，具体字段同时以该 CLI 生成的 TypeScript schema 验证。

Codex CLI 是可选依赖，插件首次使用时才启动子进程。未安装或未登录时页面显示错误或登录提示，Pi 和 Terminal 仍可使用。插件不会安装 CLI、代为登录或复制认证文件。

## 页面布局

首页采用紧凑的 **Sessions** 列表：每行显示圆点、会话标题及更新时间，默认显示前 5 个。**More** 固定在第 5 个之后，点击展开下方其余会话，再点击收起；展开后可用 **Load older conversations** 加载后续分页。输入区固定在底部，只有发送时才创建新会话。

点击列表进入会话历史，顶部显示会话标题及 pi-web 传入的 `workspace.path`。返回首页后列表重新收起为前 5 个，首页草稿与各会话草稿分别保留。工作目录由宿主工作区决定。

点击输入区的权限标签打开弹出菜单，按 **Ask for approval → Approve for me → Full access** 排列，每项包含图标和说明，当前选项右侧显示对勾。**Full access** 的菜单项和入口均使用黄色盾牌感叹号警告样式。支持方向键导航、Esc 或点击外部关闭。默认 **Full access**，选择按机器／工作区保存在浏览器中，从下一条消息生效。生成中和请求提交中禁止切换。

- **Full access**：`never` + `danger-full-access`，不请求执行审批。
- **Ask for approval**：`on-request` + `workspace-write`，审批交给用户（`user`）。
- **Approve for me**：`on-request` + `workspace-write`，由 Codex 自动审查（`auto_review`），不是无条件批准。

所选模式用于新建、恢复会话，以及每次发送的权限参数，因此已有会话也可在下一轮切换。

底部圆角输入框内，左下角为添加菜单和权限选择器，模型／思考强度选择按钮靠右、位于发送／停止共用按钮左侧，右下角为发送／停止共用按钮：空闲时显示发送箭头，发送请求提交中显示转圈并禁用，后端确认成功后切换为停止方块，执行结束后恢复发送。发送失败时恢复发送并保留草稿。首页的默认模型和思考强度来自 Codex 按工作目录解析的配置；仅当配置未指定时，才使用后端模型列表标记的默认项。进入会话后显示 Codex 返回的会话设置，发送后再次读取后端设置。模型选择窗口在选择模型或思考强度后保持打开，可连续设置；点击外部或按 Esc 关闭。

右侧 **Review** 展示当前消息页中的文件变更和轮次 diff，默认关闭，可通过顶部按钮打开或关闭。打开后，宽面板并排显示，宽度不超过 850px 时以浮层展示。变更数量是变更条目数，不是去重后的文件数。

## 添加工作区上下文

输入框左下角的 **+** 在输入区上方展开 **Add** 菜单，提供 **Files and folders** 和 **Plan mode**。选择 Files and folders 打开当前 pi-web 工作区的文件浏览器；通过 **Back to Add** 返回添加菜单。菜单支持方向键、Home / End 导航、Enter 操作、Esc 或点击外部关闭，并适配窄屏。点击目录名进入目录，↑ 返回上级；点击文件名或 **Add** 添加文件，**Add directory** 添加当前目录，也可通过目录行的 Add 选择子目录。支持筛选当前目录；选定后点击 Done、外部区域或 Esc 收起。

已选项在输入框上方显示，可逐项移除。最多选择 20 项，按机器／工作区／会话保存；发送失败时保留，发送成功后清空。本功能仅发送工作区相对路径，Codex 根据任务按需读取，不会上传本地文件、递归读取整个目录或改变工作目录。链接条目暂不支持在选择器内添加；服务端拒绝不存在或越出工作区的路径。

## 语音输入

模型选择与发送按钮之间的麦克风按钮用于语音转文字：点击开始，再次点击停止，录音时按钮标红。识别完成的文字追加到当前草稿，临时识别结果显示在输入区中，不自动发送；停止识别后可编辑并发送。录音期间禁止发送，提交中和生成中禁止开启麦克风。切换会话、工作区或卸载面板会中止识别，延迟结果不会写入其他会话。

此入口使用浏览器的 `SpeechRecognition` / `webkitSpeechRecognition`，识别语言跟随浏览器语言，需要 HTTPS 或 localhost 以及麦克风权限。浏览器不支持、权限拒绝、没有麦克风或识别网络失败时显示具体提示，保留已有草稿。识别服务由浏览器提供，某些浏览器会将语音发送至其服务端，不能保证离线使用；详见 [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)。本插件没有新增音频上传或服务端转写接口。

自动化测试覆盖结果去重、草稿追加、不自动发送、停止、会话隔离、卸载清理及错误提示；真实麦克风识别效果需在用户浏览器中验证。

## Plan 模式

在 Add 菜单开启 **Plan mode** 后，输入区底部的权限选择器右侧显示灯泡图标和 **Plan**，占位文字变为 **Describe your task to generate a plan...**。点击底部 Plan 可关闭，菜单开关同步更新；关闭后隐藏标识并恢复普通占位文字。开关不会自动发送消息，从下一条消息生效，提交中和生成中禁止切换。

Plan 状态按工作区和会话保存在浏览器，刷新后恢复，切换会话互不影响。新会话默认关闭；在首页开启后发送，创建的会话继承该模式。每次发送明确携带 `plan` 或 `default`，后端映射为 Codex 原生 `collaborationMode`，使用原生模式指令，同时保留所选模型、思考强度和权限。发送失败保留草稿、文件引用和待发送模式。

**Asking question** 仅在后端实际请求用户输入时显示，不是 Plan 的固定状态。本次添加菜单不包含 Goal、Sketch 或 Plugins。

## 对话和审批

- Enter 发送，Shift+Enter 换行；输入法组合输入期间 Enter 不发送。
- 输入框按 ↑ / ↓ 浏览成功发送的输入历史；多行文本仅在首行按 ↑、末行按 ↓ 时切换，往下翻到末尾恢复未发送草稿。历史按机器／工作区／会话隔离，优先读取 Codex 会话最近 100 条用户输入（包括 CLI 中发送的内容），首次打开历史会话也可使用；浏览器记录仅作为离线回退；组合输入、选中文本或按住修饰键时保留原有方向键行为。
- 模型和推理选项来自 app-server；选择 Default 时沿用会话默认配置。
- **Stop** 中断当前轮次，之后可继续发送消息。
- 聊天时间线参考 codex-webui：用户消息、过程说明和最终回答分别呈现；相邻工具活动按轮次分组，执行时展开、完成后收起。
- 命令卡片显示命令、输出、退出码及工作目录；文件变更显示路径和红绿差异；思考和计划使用可展开的安全 Markdown 正文。
- 支持实时思考摘要、命令输出和计划更新。最终回答前仅在后端提供轮次耗时时显示 Worked for；缺失时只显示 Worked，不推测耗时。
- 消息的操作栏同时显示时间和复制图标：用户消息为「时间 → 复制」，回复为「复制 → 时间」。时间来自 Codex 的轮次时间（用户消息及中间消息使用开始时间，最终回答优先使用完成时间），按浏览器本地时区显示；悬停时间可查看完整日期及其含义，旧历史缺失时间时不显示。手机触屏上操作栏常显。
- 回答、工具结果和代码块支持复制，成功后显示勾，约两秒后恢复复制入口；失败显示错误提示，可再次点击重试。菜单在点击外部、移走焦点或按 Esc 时关闭；选择模型或思考强度后保持打开。
- 默认使用 **Full access**。选择 **Ask for approval** 时，后端返回的审批请求显示 **Allow once / Deny / Cancel**；**Approve for me** 使用 Codex 原生自动审查。
- 请求用户输入的工具会显示问题和选项；尚不支持的交互会明确返回错误，不会自动批准。
- 审批和发送由服务端控制并发。多个页面不能重复批准同一个请求，也不能同时启动同一会话的两个轮次。

标签会显示运行中或待审批数量。首次迁移旧偏好时，会在已固定的 Terminal 后加入 Codex；之后手动隐藏 Codex 的选择会保留。未固定 Terminal 的用户可从导航菜单打开 Codex。

## 刷新、重连和数据归属

Codex 进程由 sessiond 中的服务端插件持有，切换面板、刷新浏览器或重启 Web 服务不会主动停止任务。页面通过插件的 `events` 双向通道接收变化通知，复用宿主鉴权和远程机器路由。服务端将约 30 ms 内的通知合并，浏览器再合并触发按需快照请求；空闲时不定时查询。大消息继续使用有容量限制的快照请求，避免超出通道的单帧上限。

通道断开后约 1.5 秒重连，连接成功后补一次快照；快照请求失败后约 4 秒重试。重连只读取状态，不自动重发消息或审批。切换会话会取消旧订阅；正在运行的会话在面板卸载后仍保留更新，结束后释放订阅。

由本插件执行的会话实时推送。外部 CLI 写入的历史会话采用只读读取，不接管其执行进程；需要重新加载时，可点击顶部栏的 **Reconnect** 图标。对话内容顶部不再显示 **Refresh conversation** 按钮。不支持通道的旧宿主会提示更新宿主或使用 **Reconnect**，不回退到定时轮询。

重新打开页面默认进入会话首页；草稿保存在浏览器本地，按机器、项目、工作区和会话隔离；禁用浏览器存储时，当前页面内仍保留草稿，刷新后无法恢复。浏览器站点存储中可能包含草稿正文。

app-server 退出、插件禁用或 sessiond 重启会中断进程内任务。点击 **Reconnect** 可重新初始化并恢复已持久化历史；不会恢复已经中断的工具执行。发送响应丢失时，先检查会话是否已有该条输入，再决定是否重新发送。

应用按端口隔离状态目录，但 Codex 仍使用 sessiond 用户的默认配置目录或既有 `CODEX_HOME`。因此同一账户的 Terminal、其他端口和本插件可能共享 Codex 账户及历史。不要同时在多个客户端继续同一个会话；在面板中继续 CLI 会话前，应退出持有该会话的 CLI；仅等待当前轮次结束可能仍保留写入权。

## `already has an active writer`

该错误表示同一会话已有其他 Codex 实例持有写入权，例如 Terminal 中的 CLI 或另一端口的插件。旧版插件查看快照时也会尝试恢复会话，从而触发冲突。

补丁现将未接管会话的快照改为 `thread/read` 只读历史，轮询会重新读取已持久化内容；发送消息时才尝试恢复会话。外部会话显示 **Stored history**，不提供其实时审批或停止控制。如果发送时提示占用，请退出原客户端中的该会话后重试，或新建会话。

更新补丁后需重新执行 `sh scripts/install.sh` 并手动重启对应的 `pi-web-sessiond` 才能生效。重启前先完成或停止正在运行的任务。

## 资源限制与首版边界

- 每个工作区惰性创建一个 app-server，同一插件实例最多保留 16 个工作区实例；没有运行任务和待审批的实例闲置 15 分钟后回收。
- 每个实例最多缓存 30 个会话；超限时淘汰一个空闲会话，后续可从 Codex 历史恢复。
- 每个会话展示最近 512 个条目，每页 40 个；单条显示最多 16,384 字符，超长内容标明截断。完整历史仍由 Codex 保存，可通过 CLI 查看。
- RPC 等待上限为 25 秒；超时会停止该 app-server 并明确报错，避免把未知状态当成成功。超大协议帧同样报错并停止进程。
- 工作区删除或归属改变后，插件的周期检查会在约一分钟内清理该工作区的进程。
- 首版不支持图片/附件输入、内嵌登录、会话分叉、归档管理或 Codex 与 Terminal 独立左右分屏。

禁用或卸载插件前应先停止或等待其任务完成。插件通过现有插件管理机制启停；停用会释放进程和订阅，保留 Codex 持久化历史。回退时使用原 release，或移除 `0006-codex-panel.patch` 后重新构建安装，再重启对应服务。

详细检查命令和结果见 [实施记录](codex.md)。

模型和思考强度显示 Codex 新建/恢复会话返回的生效设置，历史会话使用 `thread/read` 返回的记录值；设置变更事件同步更新界面。手动选择用于下一次发送，切换会话时清除，避免串用。接口未提供值时显示 `Model unavailable` / `Effort unspecified`，不把模型列表的默认值当作实际设置。此显示是会话配置，不是每次推理的执行遥测。

手机窄屏（面板宽度不超过 520px）使用两行顶部栏，目录单独一行；输入区按钮采用 44px 触控尺寸，输入文字为 16px，模型/文件弹窗限制在面板宽度内，Review 使用覆盖面板。底部适配安全区域，消息、代码与表格在各自区域换行或滚动。所有弹窗与原生下拉选项采用 pi-web 当前主题的背景、文字、边框及阴影颜色。

手机端（Codex 面板宽度不超过 520px）点击输入框左侧「+」，可选择模型、推理强度和 Permission mode；文件添加与 Plan mode 也在此菜单中。桌面端仍在输入框底部直接显示模型和权限选择。
