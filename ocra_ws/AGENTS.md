# Orca 配对链接维护约定

- 配对链接必须区分客户端类型：桌面端使用 `orca pair` 生成的 `scope=runtime` 链接；Android、iOS 手机端使用 `orca pair --mobile` 生成的 `scope=mobile` 链接。两者分别保存、清晰标注，不混用。
- 生成链接时，连接地址从 `data/ocra.conf` 的 `ip`、`port` 读取；配置模板不包含真实配对凭据，实际配置和凭据不提交 Git。
- 配对链接是用于首次配对的一次性凭据。配对成功后，不应把配置中保存的旧链接当作仍可用于新设备的链接；新设备或重新安装客户端后应重新获取相应类型的链接。
- 普通 `pair` 会复用尚未使用的链接；需要强制替换未使用链接时使用 `--rotate`。已经配对的客户端保存独立凭据，正常重连不需要重新配对；生成新链接不应撤销已有客户端授权。
- 后续修改安装、服务管理脚本、配置模板和文档时，保持上述桌面端/手机端区分及一次性使用规则一致。
